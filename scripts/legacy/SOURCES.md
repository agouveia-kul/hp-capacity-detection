## Notes for running
- The scripts expect `cwd = repo root` and `scripts/` on `sys.path` (they `import hp_capacity`,
  `hp_pools`, `hp_common`, and each other, e.g. `benchmark_capacity_models as B`). Import paths
  are not edited; a runner must set `sys.path` instead.
- The scripts **hard-code writes into `data/`, `models/` and `paper/figures/`**
  (e.g. `data/capacity_model_benchmark.csv`, `models/xgb_selected_features.json`,
  `models/hockey_delta_calibration.json`). They must NOT be run directly; a runner that
  redirects writes to `results/iter00_baseline/` and `data/_paperb/` is required (not yet written).
- The shared modules `scripts/hp_capacity.py`, `hp_pools.py`, `hp_common.py` and `src/heapo.py` differ
  from `../NILM/` only in line endings, and `NILM/scripts/hp_capacity.py` was last modified
  2026-09-01 13:36, before any legacy output was written. So the code that produced the legacy
  CSVs matches the current code.
- Expected sources of non-reproducibility: `hc.tune_xgb_cv` calls `hyperopt.fmin` without `rstate`
  (unseeded TPE), which affects the benchmark XGBoost, feature_select_xgb and train_swiss_capacity.
  The benchmark FFNN depends on the TensorFlow build. The downstream scripts refit XGBoost with fixed
  `sel_meta` from `models/xgb_selected_features.json`, and the hockey scripts are deterministic.
- `data/hockey_delta_calibrated.csv` has mtime 2026-09-08, a week after the other outputs
  (2026-09-01) and after the script's last edit. It may have been regenerated by a different version.
